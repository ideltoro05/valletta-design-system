# Mission Protect LMS screenshots (4:3)

Captured Nov 11, 2026 from the live platform for the US Marshals Service LMS sources-sought
response. Each image is 4:3 (about 1209x907) so it drops cleanly into a Word document.

| File | Shows |
|---|---|
| `MissionProtect_01_Manager_Course_Assignment.png` | Manager view of the courses assigned to an organization: status, assigned date, Active/Inactive availability, and the Assign Production Course / Assign Beta Content buttons |
| `MissionProtect_02_Student_Progress.png` | One student's record: watch time, sections completed (80/82), average quiz score (98%), and a progress bar for every course |
| `MissionProtect_02b_Group_Progress_Alternate.png` | Alternate for #2: the organization's learner summary (onboarded, signed in, started training, certificates earned, hours trained) above the learner list |
| `MissionProtect_03_Student_Quiz_View.png` | The student's view of a knowledge-check question with instant feedback, inside the interactive chapter player |
| `MissionProtect_04_Reports_Certificate_Export.png` | Certificate register with search, course filter, Export CSV, and one-click Export package (every certificate PDF plus a CSV register) |

**Privacy:** learner names, emails, avatars, the client organization's name and primary
contact, and the signed-in admin's name are blurred. Data is otherwise real and unaltered.
The Performance dashboard was deliberately not used: it displays demo numbers, not real data.
